# بوابات الإصدار

لا يتم نشر نسخة نهائية قبل نجاح:

1. Build x86 وx64.
2. إنشاء MSI x86 وMSI x64.
3. إنشاء WordProSuite_Setup.exe.
4. Install / Repair / Uninstall.
5. ظهور الإضافة في COM Add-ins.
6. LoadBehavior = 3.
7. تسجيل OnConnection.
8. ظهور Ribbon.
9. تنفيذ أوامر RTL والنص والجداول وPDF.
10. إغلاق Word بلا Crash.
11. إزالة الإضافة واختفاء Ribbon.
12. اختبار Office 2024 32-bit.
13. اختبار Office 2024 64-bit.
14. فحص Defender.
15. توقيع EXE وMSI بشهادة Code Signing قبل التوزيع العام.
