# المعمارية التقنية

1. Managed COM Add-in مكتوب بـC#.
2. .NET Framework 4.8.
3. IDTExtensibility2 لدورة حياة الإضافة.
4. IRibbonExtensibility لإرجاع Ribbon XML.
5. CommandRouter لتسجيل الأوامر.
6. Word dynamic COM لتقليل الاعتماد على Office PIAs أثناء البناء.
7. WinForms Command Center.
8. WiX MSI x86 وx64.
9. EXE Launcher يكتشف Office Click-to-Run Platform.
10. GitHub Actions للبناء.
11. Self-hosted Windows runner لاختبار Word 2024 فعليًا.
